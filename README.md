# US Stock Market Live Data Analysis 📊

## Project Overview
Independently researched and analyzed
daily US semiconductor and AI stock market
data for 6 months (May 2026 – Present),
tracking 9+ major tech companies.

## What I Did Daily
- Collected Open, High, Low, Close,
  Volume data for 9 stocks
- Prepared Pre-Market Opening Reports
- Prepared Post-Market Closing Reports
- Tracked S&P 500, NASDAQ, Dow Jones

## Key Analysis Done
- Valuation Analysis (P/E, Forward P/E,
  EPS, PEG Ratio, Market Cap)
- NASDAQ Prediction Framework
  (6-Checkpoint System)
- Historical Trend Analysis
  (Monthly & Quarterly Patterns)
- Macro Data Tracking (CPI, PCE, Fed,
  Non-Farm Payrolls, GDP)
- Global Market Correlation Analysis
